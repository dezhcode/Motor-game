# تست مرورگری کویرسوار

انتشار وب از شاخهٔ `codex/development` انجام می‌شود. آدرس استاندارد سایت:

https://dezhcode.github.io/Motor-game/

با هر پوش روی این شاخه، گردش‌کار **Publish KavirSavar web preview** وابستگی‌های قفل‌شده را نصب می‌کند، TypeScript و آزمون‌های بازی را بررسی می‌کند، خروجی وب را می‌سازد و فقط پوشهٔ `dist` را به GitHub Pages می‌فرستد. کارهای در حال انتشار کامل می‌شوند و جدیدترین پوش بعدی در صف می‌ماند.

برای راه‌اندازی اولیه، در Settings → Pages مخزن، Source باید GitHub Actions باشد. محیط `github-pages` باید اجازهٔ انتشار از `codex/development` را داشته باشد. این تنظیم فقط یک بار لازم است.

نسخهٔ منتشرشده در `build-info.json` کنار سایت مشخص است. اگر انتشار شکست بخورد، گزارش همان اجرا در زبانهٔ Actions علت را نشان می‌دهد؛ نسخهٔ سالم قبلی همچنان در دسترس می‌ماند.

برای تست با گوشی، لینک را باز و صفحه را افقی کن. شروع بازی، آموزش، منو، صدا، تنظیمات و منطق فیزیک در مرورگر قابل آزمایش‌اند. جزئیات مخصوص Android مانند دکمهٔ بازگشت سیستم، ویبره و بسته‌بندی نصب‌شدنی در تست APK بررسی می‌شوند. ذخیرهٔ تنظیمات و رکوردها به همان مرورگر و آدرس سایت وابسته است و با نصب APK منتقل نمی‌شود.

گردش‌کار وب، APK نمی‌سازد و خروجی ثبت‌شدهٔ Google Studio را جایگزین نمی‌کند. ساخت APK مطابق گردش‌کار جداگانهٔ موجود باقی می‌ماند؛ ساخت APK توسعه پس از تأیید نسخهٔ وب، از سورس شاخهٔ توسعه انجام می‌شود.
