# شاخه‌های پروژه

- `main`: تغییرات و خروجی Google Studio؛ APK اصلی از همین شاخه ساخته می‌شود.
- `codex/development`: تغییرات ما؛ ادغام با `main` فقط با درخواست صریح شما انجام می‌شود.

برای کار بعدی، آخرین تغییرات `main` را داخل شاخهٔ توسعه دریافت می‌کنیم و تعارض‌ها را همان‌جا رفع می‌کنیم. پوش‌های Studio روی `main` به‌طور خودکار APK اصلی را می‌سازند. فایل‌های بازی داخل APK با خروجی ثبت‌شدهٔ Studio تطبیق داده می‌شوند.

نسخهٔ وب آزمایشی از `codex/development` با هر پوش روی GitHub Pages منتشر می‌شود: https://dezhcode.github.io/Motor-game/ . جزئیات در [راهنمای تست مرورگری](web-preview.md) آمده است.
